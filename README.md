# VizHub feedback and issue tracker

This repository collects **community feedback and historical issue discussions** about VizHub. It contains issue templates and documentation, **not** the implementation of the current VizHub application.

## Submit feedback

- [Browse existing issues](https://github.com/vizhub-studio/vizhub-feedback/issues) before submitting a duplicate.
- [Open a new issue](https://github.com/vizhub-studio/vizhub-feedback/issues/new) with reproduction steps, expected behavior, actual behavior, and any non-sensitive screenshots or links.
- For a confirmed source-code issue, the relevant [VizHub organization repository](https://github.com/vizhub-studio) may provide a more specific issue tracker. Repository maintainers can redirect reports as needed.

## Scope and historical status

Older community links and Kanban boards under `datavis-tech` referred to previous organizational locations and may no longer be active. An open issue here does **not** guarantee a current support SLA or that the corresponding feature exists in the latest VizHub product.

Do not paste API keys, private project links, billing details, personal data, or authentication tokens into public issues. The current product is [VizHub](https://vizhub.com/); earlier VizHub Cloud/V2/V3 experiences should be identified explicitly in bug reports.

There is **no `package.json` or local test/build command** in this repository.
